# e-Caraka

A static Jekyll reading edition of the **Carakasaṃhitā**, a Sanskrit
treatise on medicine, with **Cakrapāṇidatta's** commentary, the
*Āyurvedadīpikā*, in IAST. Content drawn from the
[NIIMH e-Samhita](http://niimh.res.in/ebooks/ecaraka/); see `about.md`
for provenance and limitations. Built the same way as the companion
e-Suśruta site.

## Structure

- `_sutrasthanam/`, `_nidanasthanam/`, `_vimanasthanam/`,
  `_sarirasthanam/`, `_indriyasthanam/`, `_cikitsasthanam/`,
  `_kalpasthanam/`, `_siddhisthanam/` — one Jekyll collection per
  sthāna, one file per adhyāya (Cikitsāsthāna has 36 files for its 30
  chapters: Rasāyana and Vājīkaraṇa are each split into 4 pādas in the
  source — see `about.md`). Root text is in `<div class="mula">`,
  Cakrapāṇidatta's commentary in `<div class="bhasya">`, variant
  readings in `<section class="notes">`.
- `_data/sthanas.yml` — display names, subtitles, chapter counts.
  Generated by `build_ecaraka.py`; regenerate rather than hand-edit.
- `_layouts/`, `_includes/`, `assets/css/style.css` — design, the
  commentary show/hide control, and search-hit highlighting.
- `search.html` + `search-index/*.json` — client-side search. The index
  files are Liquid templates that regenerate at build time, so edits to
  the text are picked up automatically.
- `ecaraka_data/` — the raw scraped source data (`manifest.json` plus
  one JSON file per sthāna), kept for reproducibility; excluded from
  the built site.
- `scrape_ecaraka.py`, `build_ecaraka.py` — regenerate `ecaraka_data/`
  and the chapter files/`_data/sthanas.yml` respectively. Needed only
  if the source data changes.

## Local preview

```
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/eCaraka/> (adjust to match whatever
`baseurl` you set below).

## Deploying

Push to `main`; GitHub Pages builds it with the `github-pages` gem
pinned in the `Gemfile`. No plugins beyond Jekyll's built-ins are used.
Set `baseurl` in `_config.yml` to match your repo name for a
project-page URL (e.g. `/eCaraka`), or to `""` for a user/org page or
custom domain.

## TEI download

The home page offers the complete text as two unified TEI P5 files, in
`assets/tei/`: root text only (`*-mula.xml`) and root text with commentary
(`*-full.xml`). They are generated from the chapter files by
`build_tei.py`. After any change to the text, regenerate and re-validate:

    python3 build_tei.py --validate path/to/tei_all.rng

(`pip install jingtrang` provides the validator; `tei_all.rng` is in the
TEI release at https://github.com/TEIC/TEI/releases.)
